Вопрос: почему ChangeName изменяет объект, видимый снаружи, а ReplaceHero не заменяет исходную переменную?

Ответ:  ChangeName меняет объект, потому что копируется ссылка, а объект остаётся один и тот же. ReplaceHero не заменяет его, потому что new Hero() записывается только в локальную копию ссылки

Вопрос: почему следующий код не компилируется?

void Print(in int value) {

 value = 10;

}

Ответ:  Не компилируется потому что in передаёт параметр как readonly-ссылку компилятор запрещает присваивать ему значение
